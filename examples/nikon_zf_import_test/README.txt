NIKON ZF NP3 FORMAT / IMPORT TEST ONLY

PICCON01.NP3 contains neutral controls and is named LABNEUTRALTEST.
It is NOT Portra 160 or any film emulation.
Its bytes were generated by our Nikon NP3 serializer, using MIT-licensed
serialization patterns from ssssota/nikon-flexible-color-picture-control.

Our binary serializer passes exact-byte comparisons with two upstream
NP3 fixtures including one with a 257-point custom tone curve.

Camera acceptance has not been tested. Import at your own discretion and
select an unused custom Picture Control slot. Don't overwrite profiles.
Do not change firmware. Do not use this neutral trial for important photos.

When a real Portra 160 fit is verified, a separate named NP3 will be exported.
