# X100V installation

GitHub can distribute the settings sheet, but Fujifilm TETHER APP does not
provide a supported per-bank recipe import for the X100V. Do not rename the
text file to a camera file and do not overwrite a bank without a backup.

For the experimental Portra 160 diagnostic:

1. Download [`recipes/x100v/portra160-c6-experimental.txt`](recipes/x100v/portra160-c6-experimental.txt).
2. In the camera, choose an expendable custom bank such as C6.
3. Open `IMAGE QUALITY SETTING > EDIT/SAVE CUSTOM SETTING > EDIT/SAVE CUSTOM SETTING`.
4. Enter the values exactly as shown in the text file.
5. Save the bank and photograph a test scene.
6. Restore your previous bank from your backup if you do not want to keep it.

This is a manual experimental diagnostic. It is not a validated Portra 160
recipe, and Phase 2 stocks do not yet have measured X100V settings.
